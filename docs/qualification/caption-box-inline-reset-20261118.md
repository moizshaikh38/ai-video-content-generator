# Inline caption background reset correction

A separate actual Soft Backdrop baseline at /downloads/vireo-catalogue-soft_backdrop-baseline-0517-ui/pairs.png showed a slate-to-black box-color seam after the active word. ASS BorderStyle3 uses OutlineColour for the line box; inline token resets incorrectly restored the black glyph outline color. Reset now restores the resolved box color if enabled, otherwise keeps the original glyph outline. Padding, opacity, palette, grouping, position and animation controls are unchanged. This is a renderer bug fix, not a data migration or restyle.

No rounded-box, full-duration motion or reference-parity claim.
