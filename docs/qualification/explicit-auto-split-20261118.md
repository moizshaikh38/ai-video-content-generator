# Ordinary Auto split bridge, local qualification

Status: local candidate, not deployed. No Antigravity port.

Ordinary non-experimental Auto previously returned legacy group Fit before the measured split planner. This bridge lets explicitly Auto-owned fresh, source-bound tracks use the existing stable two-face + separately associated non-crossing body criteria. Every analyzed scene must be eligible, otherwise the existing legacy policy remains unchanged. No threshold loosening or universal two-face rule.

Exclusions: manual/unknown/genre ownership, stale/unverified source, missing source hash, experimental composition ownership, no permitted Split, sparse detections/bodies, identity changes, crowds, protected context, and positively measured hands crossing the split seam. Missing detections are not proof of safety. This is geometry eligibility, not semantic understanding of conversation or activity. Wider multi-source action/screen/game qualification is still required before release.
