Development only, not main-ready. Automatic suggestions now store a versioned source-key/object receipt plus transcript-content hash. Analysis checks transcript binding before AI use, rechecks after analysis and compares again in the suggestions transaction. Candidate-to-clip creation verifies current transcript identity in its transaction and copies the receipt. Current object validation happens before create; source can still change between external HEAD and DB transaction, so render rechecks too.

Quick/Studio render entry, actual worker, signed preview/download, transcript-derived caption preview/extension/export and fresh editor initialization consume the source guard. Manual saved caption cues remain readable without extension. Worker compares downloaded bytes against selection receipt SHA, checks before/after upload, and does not mark mismatches ready. These are discrete checks, not an atomic storage/DB transaction; an in-flight external object change cannot be made impossible. A post-upload rejection may leave an unpromoted object for later cleanup. Existing signed URLs cannot be retracted by this code.
