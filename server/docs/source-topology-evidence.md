# Source topology evidence admission

Developmental contract only. No production planner, setting or export caller uses it, and no default changes.

`sourceTopologyEvidence.ts` binds an explicitly diagnostic source-unit ledger to the existing `AutomaticPlanIdentity`, a freshly verified SHA256 and exact source geometry, analysis version/range and configuration. Epochs use absolute source seconds. The binder clips covered epochs to the requested item interval; gaps and overlaps are unavailable, not interpolated. It keeps complete shared scenes distinct from independent views, global graphics, attached labels and unknown content. Unit identities are local to a source-layout epoch, not participant identities or person tracks.

The returned status is `diagnostic-bound`, never automatic-ready. Both `automaticInferenceVerified` and `usefulOutputVerified` are literal false. A measured-candidate tag or a complete-coverage claim cannot self-certify. Partial/not-sampled evidence, manual labels, blended ownership and unknown content stay explicit. Rectangle containment is only a structural check, not proof of genuine semantic ownership, total source-pixel coverage, readability or valid decomposition of an opaque/blended composite. No hidden source pixels are reconstructed.

The caller must independently verify source bytes. A digest supplied by the ledger itself is not verification. Evidence-reference text is a provenance locator, not a trust credential. This binder does not detect layout transitions, infer cameras, assign people, determine global-versus-attached graphics, assess phone usefulness, optimize crops or measure export quality. It is deliberately not connected to automatic selection until those evidence and output criteria have their own qualified implementation.

## Bounded checks

28 original pure tests pass, including an authored two-epoch zero-overlay-to-PiP ledger, absolute clock/subinterval scoping, input cloning, byte/config/range/geometry changes, missing coverage, duplicate IDs, out-of-bounds geometry, dangling/cyclic attachment ownership and provenance self-certification. A focused strict TypeScript check passes. These tests use structured fixtures, not decoded moving media or a natural-source benchmark. No renderer, model, provider, mounted UI or production service was run for this step.

The automatic-output goal remains open. Independent heldout source/attachment/transition labels, measured inference and abstention, phone-useful actual moving output and matching preview/export remain separate requirements. Existing familiar-source layout tuning stays stopped. No HUD default integration, production activation, release or additional spending is implied.
